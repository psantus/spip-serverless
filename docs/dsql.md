# Aurora DSQL Driver

## Overview

SPIP uses a custom PostgreSQL driver (`dsql.php`) to connect to Aurora DSQL. It's a fork of SPIP's experimental PostgreSQL driver (`ecrire/req/pg.exp.php`) with DSQL-specific adaptations.

**Location:** `spip/overlay/ecrire/req/dsql.php`

## Connection

Configured in `spip/overlay/config/connect.php`:
- Generates IAM auth tokens via `Aws\DSQL\AuthTokenGenerator`
- Connects with `sslmode=require`
- Database: `postgres` (DSQL default)
- Table prefix: `spip` (configurable via `SPIP_TABLE_PREFIX` env var)

**Environment variables:**
```
SPIP_DSQL_CLUSTER=<cluster>.dsql.eu-west-3.on.aws
SPIP_TABLE_PREFIX=spip
```

## Key Differences from Standard PostgreSQL

### IDENTITY columns (not sequences)
DSQL uses `GENERATED BY DEFAULT AS IDENTITY` instead of `bigserial`/sequences. The driver's `spip_dsql_insert()` uses `RETURNING <primary_key>` directly instead of `RETURNING currval('seq')`.

### CREATE INDEX ASYNC
DSQL requires `CREATE INDEX ASYNC` instead of `CREATE INDEX`. The driver translates this automatically.

### No ALTER TABLE support
DSQL has very limited `ALTER TABLE` support. Cannot `DROP NOT NULL`, `SET DEFAULT`, etc. Schema changes may require table recreation.

### Case-sensitive string comparisons
DSQL/PostgreSQL is case-sensitive. SPIP's SVP plugin stores prefixes in UPPERCASE (`OTEL`, `S3UPLOAD`). Queries must match case.

### NOT NULL constraints
Unlike MySQL, DSQL strictly enforces NOT NULL. The driver's `spip_dsql_cite()` returns `'0'` instead of `NULL` for integer columns to avoid constraint violations.

## Fixes Applied (MySQL → PostgreSQL/DSQL translation)

### `spip_dsql_frommysql()` — SQL translation layer

| MySQL syntax | DSQL translation |
|---|---|
| `rand()` | `random()` |
| `TIMESTAMPDIFF(HOUR, a, b)` | `EXTRACT(EPOCH FROM (b - a)) / 3600` |
| `UNIX_TIMESTAMP()` | `EXTRACT(epoch FROM NOW())` |
| `DAYOFMONTH(x)` | `EXTRACT(day FROM x)` |
| `md5(integer)` | `MD5(CAST(integer AS text))` |
| `IN ('')` on integer columns | `IN (NULL)` |
| `0+column` | `CAST(substring(column, '^ *[0-9]+') as int)` |

### `spip_dsql_countsel()` — PHP 8.4 fix
`is_resource($r)` → `is_resource($r) \|\| is_object($r)` because PHP 8.4's `pg_query` returns `PgSql\Result` object, not resource.

### `spip_dsql_cite()` — NULL handling
```php
if (is_null($v)) {
    return sql_test_int($t) ? '0' : 'NULL';
}
```

### Empty string on integer columns
```php
} elseif ($v === '') {
    return '0';
}
```

### SELECT DISTINCT + ORDER BY
DSQL requires ORDER BY expressions in the SELECT list when using DISTINCT:
```php
if ($orderby && preg_match('/\bDISTINCT\b/i', $select)) {
    // Add ORDER BY expressions (including CASE) to SELECT list
}
```

### INSERT RETURNING
Uses column name directly instead of `currval('sequence')`:
```php
$seq = spip_dsql_sequence($table, true); // Returns primary key column name
// RETURNING id_plugin (not RETURNING currval('spip_plugins_id_plugin_seq'))
```

## OTEL Instrumentation

DB queries are traced in `spip_dsql_trace_query()`:
```php
$connexion['last'] = $query;
if (isset($GLOBALS['_otel_tracer'])) {
    $_span = $GLOBALS['_otel_tracer']->spanBuilder('DSQL')
        ->setAttribute('db.system', 'postgresql')
        ->setAttribute('db.statement', substr($query, 0, 200))
        ->startSpan();
}
$r = spip_dsql_query_simple($link, $query);
if (isset($_span)) { $_span->end(); unset($_span); }
```

## Debugging

### Enable query logging
Set `LOG_LEVEL=DEBUG` — all queries are logged via `spip_log()` on the `dsql` channel.

### Common errors

| Error | Cause | Fix |
|---|---|---|
| `null value in column "X" violates not-null constraint` | SPIP passes NULL for integer column | Fixed in `spip_dsql_cite()` — returns '0' |
| `invalid input syntax for type bigint: ""` | Empty string in IN clause | Fixed in `spip_dsql_frommysql()` — `IN('')` → `IN(NULL)` |
| `SELECT DISTINCT, ORDER BY expressions must appear in select list` | DSQL strict SQL | Fixed — adds ORDER BY expr to SELECT |
| `Missing a url function for type propres` | `sql_countsel` returning 0 | Fixed — `is_resource \|\| is_object` check |

## Schema

Tables use prefix `spip_` (configurable). Created during initial SPIP install via the wizard. Key tables:
- `spip_articles`, `spip_rubriques` — content
- `spip_auteurs`, `spip_auteurs_liens` — users
- `spip_documents`, `spip_documents_liens` — files
- `spip_meta` — configuration key-value store
- `spip_paquets`, `spip_plugins` — plugin registry
- `spip_jobs`, `spip_jobs_liens` — job queue

## Connecting Manually

```bash
TOKEN=$(aws dsql generate-db-connect-admin-auth-token \
  --hostname <cluster>.dsql.eu-west-3.on.aws \
  --expires-in 3600 --profile <your-profile> --region us-east-1)
PGPASSWORD="$TOKEN" psql \
  -h <cluster>.dsql.eu-west-3.on.aws \
  -U admin -d postgres
```
